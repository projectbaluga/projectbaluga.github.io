# Security Policy

## Supported versions

Security fixes are currently made against the default branch (`main`). Older snapshots may not receive fixes.

## Reporting a vulnerability

Please do not publish exploit details, credentials, personal information, or proof-of-concept attacks in a public issue.

To report a suspected security vulnerability, email **projectbaluga@gmail.com** with:
- A concise description of the affected feature or file
- The potential impact
- Reproduction steps that do not access or expose other people's data

Please allow time for the project maintainer to review the report. Do not perform destructive testing, access data that is not yours, or disrupt the public website or API.

## Scope

This policy covers the ProjectBaluga website source code and its publicly operated website/API. Third-party services (including GitHub, Cloudflare, Workers AI, and FormSubmit) remain subject to their own security policies.
